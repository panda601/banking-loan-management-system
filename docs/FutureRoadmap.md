# Future Roadmap (V2.0 & Beyond) - BLMS

## Overview
Planned enhancements and feature expansions for upcoming BLMS releases.

---

## 1. Release V2.0 (Target Q3 2026)
- **External Credit Agency Integration**: Integration via Named Credentials and REST APIs to fetch real-time CIBIL / Experian credit scores.
- **AI Agentforce Conversational Assistant**: Autonomous AI bot empowering borrowers to query EMI schedules, payment history, and loan status over chat.
- **E-Signature Document Verification**: Integration with DocuSign / Adobe Sign for paperless loan contract execution.

---

## 2. Release V3.0 (Target Q1 2027)
- **Mobile SDK Integration**: Native mobile app integration for loan intake and instant push notifications for due dates.
- **Automated Direct Debit (NACH / ACH)**: Automated payment collection via core banking direct debit endpoints.
